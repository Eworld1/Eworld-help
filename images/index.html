📲 Install Eworld-help

Free. No app store needed.

iPhone / iPad (Safari): tap Share (the square with an arrow) → Add to Home Screen → Add.

Android (Chrome): tap the ⋮ menu → Install app (or Add to Home screen).

Windows (Chrome or Edge): click the install icon at the right end of the address bar, or open the menu → Apps → Install Eworld-help.

Mac: in Chrome or Edge click the install icon in the address bar. In Safari choose File → Add to Dock.
